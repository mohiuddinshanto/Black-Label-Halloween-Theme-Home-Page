Standalone, enterprise-grade Lucky Wheel gamification plugin for WooCommerce with zero external dependencies.

== Description ==
Spin & Win for WooCommerce boosts your store conversions and captures qualified leads by offering shoppers an engaging interactive lucky wheel.

= Standalone Architecture (Zero External APIs) =
* 100% self-contained: No third-party services, no paid API keys required.
* Server-side probability calculation ensures results cannot be manipulated from browser DevTools.
* HPOS (High-Performance Order Storage) compatible out of the box.
* Built-in Anti-Abuse security: Disposable email blacklist, honeypot traps, built-in math CAPTCHA, and IP/cookie rate limiting.
* Dynamic coupon generation and automatic checkout application via WooCommerce session.
* Customer "My Account" tab displays all won coupon rewards.

== Installation ==
1. Download the 'spin-win-woocommerce.zip' file.
2. In your WordPress admin, go to Plugins > Add New > Upload Plugin.
3. Select 'spin-win-woocommerce.zip' and click Install Now.
4. Activate the plugin.
5. Go to WooCommerce > Spin & Win to configure slices, rules, and colors.
